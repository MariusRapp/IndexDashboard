Refresh button setup

The button starts the data update on GitHub. For that, this device needs a GitHub token once. It is saved only in this browser.

  1. Create a token on GitHub
  2. Repository access: Only select repositories → IndexDashboard
  3. Permissions: Actions → Read and write (nothing else)
  4. Generate, copy and paste it here:

No token at hand? Run the update on GitHub (“Run workflow”).
